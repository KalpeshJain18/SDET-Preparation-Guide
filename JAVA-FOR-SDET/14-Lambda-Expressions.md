# 🧠 4. Functional Interface Connection ⭐

## What is it

Lambdas work with Functional Interfaces only.

---

## Key Components

- Single abstract method
- Functional programming
- Interface implementation

---

## How to Answer (Interview Style)

Lambda Expressions require Functional Interfaces because they provide implementation for single abstract methods.

---

## Practical Example

```java
interface Test {

   void show();
}

Test t = () -> {
   System.out.println("Hi");
};
```

## Common Mistakes
