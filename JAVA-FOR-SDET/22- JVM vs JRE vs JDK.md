# 🧠 1. What is JVM

## What is it

JVM stands for Java Virtual Machine.

---

## Key Components

- Executes bytecode
- Platform independence
- Memory management
- Garbage collection

---

## How to Answer (Interview Style)

JVM is a virtual machine responsible for executing Java bytecode and providing platform independence.

---

## Practical Example

```text
.java
→ .class
→ JVM executes
```

---

## Common Mistakes

- Confusing JVM with JDK
- Weak execution understanding

---

## Expected Interview Questions
